# A két dungeon festett háttérfázisai

Create one restrained next animation phase of each supplied painted Japanese fantasy background, preserving the exact native size, composition, palette, lighting and all architecture. Do not move floors, stairs, pillars, gates, battlements, banners, chains or furniture. No new objects, text, particles or camera movement.

- Yomi courtyard west/center/east: only existing distant smoke/cloud forms gently change.
- Yomi crypt: only the existing small flames vary.
- Yomi throne hall: only clouds visible through the broken roof change.
- Sect forecourt, hall and sanctum: only existing clouds/mist through the open sky change.

Források: `dungeonCourtyardWest/Center/East`, `dungeonCrypt`, `dungeonThrones`, `cultDungeonForecourt/Hall/Sanctum`. A képekhez külön, natív méretű `MotionPhaseB` bejegyzés és kézzel kijelölt, befelé halványuló részlet tartozik. A teljes B festmény nem váltja fel az eredeti hátteret.
