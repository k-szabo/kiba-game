# Rejtett arénák festett háttérfázisai

Az eredeti képekhez visszafogott második pillanat készült, azonos nézőponttal, mérettel és festett stílusban. A futó játék csak a kézzel kijelölt, befelé halványuló részleteket használja.

Common constraints: preserve exact source lighting, exposure, palette, composition, architecture and foreground floor. No camera motion, global warp, detached particles, extra objects, text or redesign. One restrained next animation phase for a slow A/B crossfade.

- Angel ruins: only distant valley mist and open-sky clouds change; stone angels, columns and bridge fixed.
- Cult cave: existing brazier and candle flames change contour; bowls, ropes, torii, stairs, walls and sigils fixed.
- White serpent cave: existing waterfall ribbons, lake ripples and mist change; cave walls, roots, shrines and floor fixed. The current game mask samples only the lake.
- Winged serpent roost: existing sky clouds change; bridges, islands, spires and crystals fixed.
- Demon Slayer arena: distant smoke and lava ribbons change; cliffs, torii, temples and foreground floor fixed. The current game mask samples only distant smoke.
